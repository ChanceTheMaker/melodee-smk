03 / FIRST NOTES

Start playing.

  1. Open Studio or Simulator. If audio is blocked, click Browser Studio or play a simulator key.
  2. Use your mouse, touch screen or computer keys. In Simulator, 1–8 play the top pads; Shift+1–8 play the bottom pads.
  3. For a MIDI controller, choose Enable USB-MIDI input, allow access, then select its input.
  4. Export your session for a backup. Studio and Simulator share songs, project slots, preset banks and settings in this browser.
HARDWARE PORT / IN DEVELOPMENT

Try the sound. Test the port.

This preview runs Melodee’s synthesis and UI code in your browser. The first SMK hardware build compiles, but it has not been tested on a device.

A public development installer is now available with Pro/Elite package validation and a bounded SMK update loader. Hardware saves, sample uploads, USB audio, TRS and Bluetooth are disabled; this candidate still needs a physical-device test.

Browser sessions retain current music, all pattern banks, projects A–D, saved presets, favorites and settings. Session imports require the matching browser runtime version.
