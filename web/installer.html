Prepare your installation

  1. Export any important projects and presets from your current firmware. Melodee cannot load those device saves yet.
  2. Close Studio, Simulator and other MIDI apps. Use current desktop Chrome or Edge with a direct USB data connection.
  3. Select your model and the firmware currently on your SMK. Preparation checks the files without connecting to your device.
  4. After preparation, confirm the notice and click Install. Allow MIDI/SysEx access, and leave power and USB connected throughout.

Requires the portable SMK updater (identity 922 or newer). Older private builds are refused before starting an update.

Use an official file already on this computer

Optional fallback if automatic download is unavailable. Select the unmodified official Pro 016 or Elite 016 .fwsc for your model. It stays on this computer.

Preparing files does not flash anything. Installation starts only after you click Install and grant MIDI access.

What’s in this build

  • Native Melodee synthesis and 240 × 240 interface
  • SMK piano, pads, encoders, faders, wheels and sustain mappings
  • USB MIDI and a bounded RAM update loader

Still being integrated

Hardware project/preset saves, sample uploads, USB audio, physical TRS MIDI and Bluetooth are disabled. Browser session saving works separately in Studio and Simulator.

Pro and Elite package generation and loader behavior pass offline tests. Physical boot, controls, sound and update handoff still need testing. The stock Elite 016 handoff has a known unresolved report; this installer stops if the exact expected loader does not appear.

Protected data

The custom RAM updater validates the flash profile and calibration, verifies the complete package before erasing, and limits writes to the application region. The stock route uses the matching official 016 loader. Neither route is a backup of your existing music.
